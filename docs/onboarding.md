# Onboarding

Welcome to the LINC project!  Follow the steps below to get set up.

## 1. Send your details to Kabi

Email [kabi@mit.edu](mailto:kabi@mit.edu) with:

- Your email address
- Your GitHub username
- The LINC team you will be on (see [LINC teams](https://connects.mgh.harvard.edu/people/))

## 2. Get added to LINC communication and tools

Kabi will add you to:

- The [LINC Slack](https://mit-lincbrain.slack.com/) workspace
- The Computational team weekly meeting
- [GitHub (lincbrain)](https://github.com/lincbrain)
- [Neuroglass](https://linc.neuroglass.io)
- [WebKnossos](https://webknossos.lincbrain.org/)

## 3. Sign up for data platform accounts

Create accounts on the following sites.  Kabi will approve your accounts.

- [lincbrain.org](https://lincbrain.org)
- [dandiarchive.org](https://dandiarchive.org)

## 4. (Optional) Get access to the MIT cluster

If you need to run analyses on the MIT Engaging cluster, follow the instructions on the [Engaging Cluster](engaging.md) page.

## Checklist

- [ ] Emailed Kabi with email, GitHub username, and LINC team
- [ ] Joined the LINC Slack and the Computational team weekly meeting
- [ ] Added to GitHub, Neuroglass, and WebKnossos
- [ ] Signed up on lincbrain.org
- [ ] Signed up on dandiarchive.org
- [ ] (Optional) Set up access to the Engaging cluster
